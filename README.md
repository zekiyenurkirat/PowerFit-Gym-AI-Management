# 🏋️‍♂️ PowerFit Gym - AI Management System

This project is a modern, comprehensive gym management web application built with a robust backend and Artificial Intelligence integration to provide personalized fitness experiences.

## 🚀 Key Features
* **AI-Powered Recommendations:** Integrated with Google Gemini API to offer users personalized workout and diet plans.
* **Member Management:** Secure registration, login, and user profile management systems.
* **Modern Architecture:** Developed using the MVC (Model-View-Controller) design pattern for scalable and maintainable code.

## 🛠️ Technologies Used
* **Backend:** C#, ASP.NET Core MVC
* **Artificial Intelligence:** Google Gemini API
* **Database & ORM:** SQL Server, Entity Framework Core (Migrations)
* **Frontend:** HTML5, CSS3, Bootstrap, JavaScript (wwwroot assets)

## 📂 Project Structure
* `Controllers/`: Handles incoming HTTP requests and application logic.
* `Models/`: Represents the data structures and database schema.
* `Views/`: User interface components and Razor pages.
* `Services/`: Contains core business logic and AI integration services.
